# DateXray 配图生成

配图工作区位于 `/channels/x` 每版英文草稿下方。配图是独立的 X 附件，不写入内容台账，也不改变复制按钮的英文正文。

## 模板与主题

- 数据／观点卡：只有原始素材同时包含“一整行英文数字证据”和单独的 `Source: 英文来源` 行时，才允许使用大数字；否则生成无数字观点卡。
- 对话摘录卡：真实引用必须逐字匹配素材中的英文引号内容或 `Name: dialogue` 行。没有对话时，界面会要求补充素材，或明确勾选虚构教学示例；后者永久在图内显示 `Hypothetical example`。
- 统一画布为 `#0f172a` 深色品牌底。反诈或警示内容使用红橙色，公开构建使用绿色，其他中性内容使用蓝紫色。

## 生成和编辑边界

每次点击“生成配图”只发出一次 DeepSeek 请求，输入固定为所选版本当前英文、本批原始素材、内容类型、模板和虚构选项。切换版本、修改英文或晚到响应不会错配；旧图会标为过期并禁止下载，但编辑内容继续保留。

所有图内字段必须为英文，并在画布外显示中文对照；中文对照必须保留英文中的所有阿拉伯数字。标题、支撑说明和可选产品钩子可微调；逐字引用、数字证据、数据来源及含数字的证据标题保持只读。行为标签来自有限列表，不给人贴标签。

## PNG 导出

导出使用应用内打包的 Geist 字体和 SVG DateXray 标志。浏览器先按设备像素倍率渲染，再归一到 1200×675 PNG；字体和图片资源就绪后才导出。检测到真实文字溢出时会要求缩短，不截掉限定语，也不无限缩小字号。失败时现有预览和编辑内容保留。
